## Sobre o projeto

O projeto consiste em uma página web desenvolvida como atividade prática do curso, utilizando uma estrutura simples com HTML, CSS e JavaScript.

A atividade também serviu para praticar o uso do Git e do GitHub durante o processo de desenvolvimento e versionamento do projeto.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura

- `index.html` — estrutura da página
- `style.css` — estilos e layout
- `script.js` — funcionalidades e interações da página

## Objetivo

Praticar os fundamentos de desenvolvimento web e os conceitos básicos de controle de versão utilizando Git e GitHub.
